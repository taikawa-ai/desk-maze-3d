# 机とベニヤの迷路づくり

教室の平面図から、**学校の机＋ベニヤ**で作る迷路(脱出ゲームなど)の3Dイメージを作るWebアプリです。
スマホ・タブレットのタッチ操作で使えます。サーバーは不要で、すべてブラウザの中で動きます。

## 決まり(組み立て方)
- 壁 = 机を並べた列(厚み=机の奥行き40cm) ＋ 片側の面に立てたベニヤ(90×180)
- ベニヤ1枚に机1か所。机は2段で、上の机は逆さにして天板どうしを合わせる
- 90で割り切れない壁は、最後のベニヤを端にそろえて重ねる(「数」タブに注意が出ます)
- 大きさは「教室・保存」タブで変えられます

## 使い方
- **図面**: 「描く」で指でなぞると壁(横か縦にそろう)。「選ぶ」でタップ→ドラッグで移動。2本指で拡大・移動
- **壁**: 選んだ壁の位置・長さを数字で直す／数字で壁を足す
- **3D**: ぐるっと(指で回す)・真上・歩く(入口から中を歩く。ボタンで進む・回る、画面ドラッグで見回す)
- **数**: 机・ベニヤの数、注意(割り切れない・机がぶつかる・教室からはみ出す)
- **教室・保存**: 教室の大きさ・入口、下書き写真、保存(.json)、書き出し(.png / .glb / .obj)

作業中の図面は端末のブラウザに自動で残ります。別の端末に渡すときは「図面を保存(.json)」を使います。

## GitHub Pages で公開する
1. GitHub で新しいリポジトリを作り、このフォルダの `index.html` `app.js` `style.css` を置く
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

3D表示には three.js(jsDelivr から読み込み、0.160.0 に固定)を使っています。
